# Clear writing and self-explanatory code

- Prefer clear names and small functions over comments.
- Comment only to explain non-obvious intent (why), never to restate what the code does.
- Keep docs and messages concise and specific.
- Respect existing project style; do not bundle third-party proprietary guidelines.
